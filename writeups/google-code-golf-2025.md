## Problem Description

**Code Golf** is the art of writing the shortest possible program that correctly solves a given problem. In this competition, participants implemented solutions to various programming tasks using the fewest number of characters (bytes).

### The Challenge

- Implement correct solutions to ARC-style programming tasks
- Minimize code length while maintaining correctness
- Optimize for post-compression file size

### Evaluation

Solutions evaluated on:
1. **Correctness**: Must pass all test cases
2. **Code length**: Fewer characters = better score
3. **Compression**: Some tasks evaluated on post-zip file size

### 4th Place: Parallel Sampling + Rule-Based Prompt Generation

**Team**: Jokrasa, Kohei (confirm), Thunder Thunder

*"I spent a ton of time on code golf for the first time in about 20 years"*

*"Solutions were 98% generated by an LLM and only about 2% by human effort"*

#### Core Strategy: Parallel Sampling

Used **gpt5-codex** with tools in parallel:

```
For each task:
├── Run 10-30 turn conversation session
├── Each turn:
│   ├── Generate 4 parallel versions
│   ├── Evaluate each for correctness
│   └── Select shortest valid code
└── Continue with follow-up prompt
```

**Session Duration**: 5 minutes to over 1 hour per turn, depending on difficulty.

#### Rule-Based Prompt Generation

Generated prompts dynamically using code's **Abstract Syntax Tree (AST)**:

| AST Pattern | Generated Prompt |
|-------------|------------------|
| No regex used | "Try to use the regex re package to code golf" |
| Contains loops | "Try converting them into recursive functions" |
| Uses `def` | "Use lambda instead" |

**Base Follow-up Prompt**:
> "Please make it as short as possible in bytes for Code Golf and tell me the file size."

#### Exploration Strategies

**Stop Criterion**: Terminate if no improvement for $s$ consecutive turns.

**Exploration Prompts** (when stuck):
- "Analyze the test cases generation code"
- "Rethink a more compact algorithm"

#### Platform Usage

**Codex Cloud (Web)**:
- 15 parallel conversation sessions
- 4 parallel versions per turn (N=4)
- ChatGPT Pro subscription limits

**codex exec (CLI)**:
- Docker container for safe execution
- Results logged to SQLite
- Ran while sleeping or during work

#### Key Innovation: Escaping Local Optima

**Problem**: Model gets stuck using existing solution patterns.

**Solutions**:
1. **Clean sandbox environment** for each new session (CLI)
2. **Explicit instruction**: "Ignore the code that's already implemented and write it from scratch"

#### Compression-Friendly Code Optimization

In final 2 weeks, optimized for **post-compression file size**:

**Prompt**:
> "This must be achieved with minimal Kolmogorov complexity and is evaluated based on the file size after zip compression."

**Example Diamond Solution** (Task 324):
```python
def p(a):
 n=sum(a,[]);c=n.count;o=n[c(n[0])<4];f,s={},{()}
```

#### Additional Techniques

- **Encouragement prompt**: "Shorter code is known to exist" (when LLM stops trying)
